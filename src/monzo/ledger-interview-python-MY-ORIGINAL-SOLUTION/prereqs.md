# Prerequisites (stuff you need to have installed to run this code)

To be able to run the code in the exercise, you will need to install some software onto your machine.  We've written the exercise code to have as few dependencies as possible to make the set up simple.

We recommend installing the required tools at least a day _before_ your scheduled interview, and setting aside at least an hour for it.

* A computer with a microphone and preferably a camera
* Python 3 (at least 3.6)
  * Installation instructions for each operating system can be found on the [Python homepage](https://www.python.org/)
* A text editor or IDE
  * There are no restrictions on which text editor or IDE to use
  * If you don't already have a text editor we recommend [Pycharm Community Edition](https://www.jetbrains.com/pycharm/download/), which is free.

To verify your installation and to familiarise yourself with the style of tests in the exercise code, try out the [basic example](https://docs.python.org/3/library/unittest.html#basic-example) in the unittest documentation.

If you prefer to [use pytest to run the tests](https://docs.pytest.org/en/stable/how-to/unittest.html), please install it before the interview and ensure it works. There is no advantage to using either test runner.
